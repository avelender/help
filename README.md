# SecuTar Help

Каталог полезных интернет-ресурсов для инженеров систем безопасности:
<https://help.secutar.org>

Статический сайт без сборки: HTML + CSS + JavaScript. Весь каталог лежит
в одном файле — [`data/catalog.json`](data/catalog.json).

- Как добавлять и менять записи — [`docs/ADMIN.md`](docs/ADMIN.md)
- План проекта и общая документация — [`docs/PLAN.md`](docs/PLAN.md)

## Быстрый старт для администратора

1. Откройте `data/catalog.json` (на GitHub нажмите иконку карандаша).
2. Добавьте/измените записи по образцу из `docs/ADMIN.md`.
3. Нажмите *Commit changes* — сайт обновится автоматически через 1–2 минуты.

## Локальный просмотр

Открывать `index.html` двойным щелчком нельзя (браузер блокирует загрузку
JSON с диска). Нужен любой локальный сервер, например:

```
python -m http.server 8000
```

затем откройте <http://localhost:8000>.

## Публикация

Размещается на GitHub Pages через GitHub Actions
(`.github/workflows/deploy.yml`): перед публикацией каталог автоматически
проверяется скриптом `scripts/validate.js`. Домен привязан через `CNAME`.
